# 3D-wooden-house
This modest Japanese-style wooden row house—known as Nagaya (長屋)—dates back to the Japanese colonial period-the Showa ear, most likely built in the 1930s–1940s. Characterized by its cedar timber framing, horizontal rainscreen weatherboards, and dark Japanese roof tiles, it embodies a classic pre-war urban dwelling.

This 3D digital heritage preservation project created by Elements Lab (實驗元素工作室), reconstructing a Showa-era wooden house in Tainan, Taiwan, and reviving the everyday memories of the 1960s. 

Dedicated to my best friend's parents.
